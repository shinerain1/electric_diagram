# 输出结构

每张图纸生成 `automatic` 和 `audit` 两类目录。

## 主拓扑 JSON

`<图名>/automatic/<图名>_自动识别.json` 是后续任务的主入口。

- `equipment`：详细层物理元件。
- `terminals`：元件侧接口及其导线投影位置。
- `connectivity_nodes`：由导线连通分量形成的物理连接节点。
- `derived_device_edges`：从共享连接节点推导的元件关系。
- `crossings`：端点连接、T 形接入、导通和不导通十字交叉。
- `detailed_topology`：上述物理对象的完整快照。
- `engineering_topology`：柜体、变压器、容器从属关系、工程节点和供电关系。

详细层采用：

```text
元件 -> 接口 -> 连接节点 -> 接口 -> 元件
```

工程层采用：

```text
柜体/母线分段 -> 工程连接节点 -> 变压器或其他设备
```

每个识别对象尽量保留 DXF 坐标、原始 HANDLE、块引用路径、模板、
置信度和判断依据，以便返回原图复核。

## 辅助输出

- `<图名>_自动识别元件.csv`：详细元件清单。
- `<图名>_工程层设备.csv`：工程层设备清单。
- `<图名>_工程层关系.csv`：工程供电关系。
- `<图名>_自动识别复核.png`：详细层叠加图。
- `<图名>_工程拓扑复核.png`：工程层叠加图。
- `audit/<图名>_独立模板识别审计.json`：候选、拒绝原因和图层过滤证据。

## 下游使用

可把设备和连接节点作为图节点，把接口归属、设备关系和容器从属关系作为边，
用于上下游查询、供电路径分析、人工修正、图数据库导入或其他电网模型转换。
