# 方法概览

当前流程采用“学习式元件边界、导线补充、逻辑校正、两级拓扑”的组合方式。

1. 过滤关闭、冻结和不打印图层，递归展开可见块引用并保留来源路径。
2. 将DXF实体标准化为匿名图元，梯度提升树产生初始导线概率，四层边感知门控残差图网络输出元件主体、接口短引线和主导线概率。
3. DXF迁移后的同元件边模型判断相邻图元能否合并；迭代边界算法从高置信种子出发，重新吸收归属唯一的短引线和局部主体，并阻止长母线连接多个元件。
4. 每个学习式边界作为不可由模板阶段删除的元件候选，与全部标准模板比较；无法可靠分类时保存为UnknownComponent。
5. 元件占用的图元不再参与导线提取，剩余长轴向图元形成导线网络。
6. 端点在 `0.10H` 内吸附，T 形接入使用 `0.25H` 容差；交叉点结合圆点标记判断导通。
7. 从元件边界建立接口并投影到导线，形成详细物理拓扑。
8. 使用电气逻辑知识库补充连接上下文和功能角色，并形成工程拓扑。

规范化识别尺度为 `H=100`。对于明显整体缩小的复杂工程图，程序只进行有限的
原始单位换算；所有阈值仍以规范化后的 `H` 表示。

当前实现能够批量生成候选拓扑，但不是无需复核的生产级电网模型。复杂柜内关系、
不完整符号和不同设计单位的符号风格仍需要更多独立标注图纸验证。
