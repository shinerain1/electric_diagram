# 方法概览

当前流程采用“元件优先、导线补充、逻辑校正、两级拓扑”的组合方式。

1. 过滤关闭、冻结和不打印图层，递归展开可见块引用并保留来源路径。
2. 将闭合图形、圆、斜线和短图元组成元件候选。
3. 完整块优先作为元件候选；自由图形候选与全部标准模板比较。
4. 元件占用的图元不再参与导线提取，剩余长轴向图元形成导线网络。
5. 端点在 `0.10H` 内吸附，T 形接入使用 `0.25H` 容差；交叉点结合圆点标记判断导通。
6. 从元件边界建立接口并投影到导线，形成详细物理拓扑。
7. 使用电气逻辑知识库补充连接上下文和功能角色。
8. 将柜体作为容器，进一步形成工程设备、工程节点和柜体—变压器关系。

规范化识别尺度为 `H=100`。对于明显整体缩小的复杂工程图，程序只进行有限的
原始单位换算；所有阈值仍以规范化后的 `H` 表示。

当前实现能够批量生成候选拓扑，但不是无需复核的生产级电网模型。复杂柜内关系、
不完整符号和不同设计单位的符号风格仍需要更多独立标注图纸验证。
