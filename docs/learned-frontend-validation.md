# 学习式前三步替换验证

## 替换范围

默认入口只替换原流程的前三步：DXF图元标准化、图元分类和元件边界分割。模板识别、接口提取、导线连通、电气逻辑、详细拓扑和工程拓扑继续使用原有稳定实现。

部署前端包含三个已保存模型：

- `base_conductor_deployment.joblib`：18维几何特征的初始导线概率；
- `component_side_dxf_deployment.pt`：四层边感知门控残差图网络，输出主体、接口和主导线概率；
- `same_component_edge_dxf_deployment.joblib`：判断相邻图元是否属于同一个元件。

第三步不会把第二步分类当成不可修改的结论。它从高置信图元出发反复吸收归属唯一的相邻图元，并合并互为唯一邻居的局部碎块。长母线、跨越多个元件的桥接线和范围过大的候选保持排除。

## 同口径结果

验证使用六张已有HANDLE级拟人工标注，比较每个真值元件与自动元件边界之间的最佳集合F1。两种程序都不在推理时读取标注。

|指标|GitHub最初提交|新版前三步|变化|
|---|---:|---:|---:|
|平均真值最佳边界F1|9.86%|94.22%|+84.36个百分点|
|元件HANDLE精确率|88.39%|96.63%|+8.24个百分点|
|元件HANDLE召回率|24.75%|93.13%|+68.38个百分点|
|元件HANDLE F1|38.67%|94.84%|+56.17个百分点|
|边界F1不低于0.80的元件比例|10.56%|87.46%|+76.90个百分点|
|误合并率|0%|0%|不变|

新版前三步输出316个候选，真值为303个；GitHub最初提交只输出32个候选，因此旧版较高的候选精确度主要来自大量漏检。

## 评价限制

六张DXF参与过弱监督迁移训练，报告属于按图纸分组折外验证和部署诊断，不是完全未见设计单位的最终盲测。该结果足以确认新版替换旧版不会在现有任务上退化，但后续仍需增加不参与迁移训练的DXF进行独立验证。

六层联合节点—边—实例模型在SVG/XML严格模板互斥测试上表现较好，但未经DXF迁移时在这六张DXF上的平均边界F1只有62.74%，因此没有直接作为DXF默认模型。仓库保留相应研究代码，生产入口采用已经完成DXF迁移的模型组合。
